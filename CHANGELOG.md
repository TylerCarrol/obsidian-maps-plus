## [0.1.0] - 2026-10-18

### Added

- Areas with coordinates, fill color, stroke colour
- Routes with coordinates, color
- Overlap areas with rules and colors
- Point reduction, to render quicker on maps with many points
- Edit mode to drag-and-drop points
- Optional snap-to-points in edit mode
